# 다른 하루 · Phone Stories
React + TypeScript + Vite + CSS. 백엔드가 없는 가상 스마트폰 데모입니다.

## 실행
```sh
npm install
npm run dev
```
표시되는 로컬 주소(기본 http://localhost:5173)를 엽니다.
```sh
npm run build
npm run preview
```
`build`는 TypeScript 검사 후 `dist/`를 생성합니다.

## 주요 파일
- `src/data.ts`: 네 인물의 기종, 배경, 앱 순서, 독, 날씨 위젯 설정.
- `src/Phone.tsx`: HTML/CSS 기기 프레임, 상태 표시줄, 잠금 해제, 홈 화면과 기존 앱 연결.
- `src/main.tsx`, `src/style.css`: 회색 배경, 기기 전환, 기종별 외형과 반응형 크기.
- `src/messages/`: 인물별 읽기 전용 대화 목록과 전체 문자 기록.
- `src/music/`: 곡 목록, Now Playing, 재생·일시정지·탐색·이전/다음 곡과 앱 이동 중 재생 유지.
- `src/photos/`: 사진 격자와 원본 비율의 확대 화면, 좌우 스와이프.
- `src/youtube/`: 인물별 시청기록과 공식 iframe 플레이어, 재생 오류 안내.
- `src/calls/`: iOS/One UI 최근 통화와 상세 정보.
- `src/notes/`: 고정 메모 정렬과 원본 공백·줄바꿈을 보존하는 전체 본문.
- `src/settings/`: 인물별 iOS/One UI 읽기 전용 설정 화면.
- `public/`: MP3 50개, 원본 사진 12개, 배경화면 4개와 기본 커버.
- `*_DATA.md`: 앱별 데이터 구조와 원본 파일 설명.

## 조작
오른쪽 화살표 또는 하단 네 개의 점으로 기기를 선택한 뒤 휴대전화 화면을 위로 35px 이상 스와이프하거나 열기 버튼을 누릅니다. 아이콘을 누르면 해당 앱이 열립니다. 앱의 홈 버튼이나 하단 막대로 홈에 돌아갑니다. 오른쪽 전원 버튼으로 다시 잠급니다. 인물을 바꾸면 새 인물은 잠금 화면에서 시작합니다.

## 위젯 설정
`widgets`의 `col`과 `row`는 1부터 시작합니다. 홈은 4열이며 `width`, `height`가 차지할 셀 수입니다. 현재 4행 안에 위젯을 배치했습니다. 앱은 별도 그리드여서 위젯과 겹치지 않습니다. 배치를 확장할 때 화면 높이를 함께 확인하세요.

## 범위와 외부 연결

날씨는 고정 데이터이며 실제 기기나 실시간 날씨 API에 연결되지 않습니다. CSS 외형은 화면 탐색용 근사치이고, iPhone 18 Pro 외형은 임시 디자인으로 구분합니다. 잠금 화면 시계는 브라우저 현지 시간을 사용하며 통화·메모 날짜는 제공 데이터의 시간대를 보존합니다.

YouTube 썸네일·플레이어·공식 메타데이터 조회에는 인터넷 연결이 필요합니다. 공식 정보가 확인되지 않은 제목·채널은 임의로 채우지 않습니다. 현재 확인 범위와 외부 접근 제한은 [YOUTUBE_DATA.md](YOUTUBE_DATA.md)에 기록돼 있습니다.

## 저장소에 포함하지 않는 파일

`node_modules/`, `dist/`, 로그, `.env*`, 인증서·개인 키와 로컬 인증 설정은 제외합니다. 실행에 필요한 코드, `package-lock.json`, `public/` 원본 파일과 정적 JSON은 포함합니다. 현재 호스팅의 `.openai/hosting.json`은 사이트 연결을 위한 환경별 파일이므로 GitHub 전달본에서 제외합니다.
